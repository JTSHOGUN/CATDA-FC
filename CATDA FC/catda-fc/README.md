# CATDA FC  ·  official website, revision 2

Multi-page static site for **CATDA Football Club** (The Lufula Boys), Kampala,
Uganda. No dependencies, no framework, no build step beyond the page generator.

Read in this order:

1. `LAUNCH-CHECKLIST.md`  ·  what blocks launch and what is already verified
2. `ANALYSIS.md`          ·  fact validation, brand system, IA, security design
3. `VERIFICATION-LOG.csv` ·  every factual claim, its status and its source

---

## Run it

Content loads from `assets/data.json` over HTTP, so serve the folder:

```bash
cd catda-fc
python3 -m http.server 8080 --bind 0.0.0.0
```

Deploy by pointing any static host at this folder. `netlify.toml`, `_headers`,
`_redirects` and `.htaccess` are picked up automatically. DNS and TLS for
`catdafc.com` are the club's step, see the launch checklist.

## Update content

All editable content lives in `assets/data.json`. No page hardcodes club facts.

| To change | Edit |
|---|---|
| Next fixture | `nextFixture` |
| A result | append to `results`; `status` = win, loss, draw, or `unrecorded` for TBC |
| League table | `standings.rows`, with `"us": true` on CATDA's row |
| News post | prepend to `news` |
| Cup tie | prepend to `cupTies` |
| Squad | `people.squad` |
| Partners | `partners.clubPartners` |
| Contacts, socials | `club` |
| Footer date stamp | `meta.dataUpdated` |

Match object shape:

```json
{ "date": "2026-09-20", "comp": "FUFA Big League", "md": "MD1",
  "venue": "Bugolobi Coffee Grounds (H)", "home": "CATDA FC", "away": "Opponent",
  "hs": 1, "as": 0, "status": "win", "note": "Optional one-line context." }
```

Validate after editing:

```bash
python3 -c "import json; json.load(open('assets/data.json')); print('ok')"
```

## Rebuild pages and deployment files

Pages, `robots.txt`, `sitemap.xml`, `_headers`, `_redirects`, `netlify.toml`,
`.htaccess` and `.well-known/security.txt` are all generated. Never hand-edit
them. Edit `build.py` and re-run:

```bash
python3 build.py
```

`build.py` also recomputes the CSP SHA-256 hashes for the inline JSON-LD
blocks. If you change the JSON-LD, the hashes in `_headers` update with it.

To add a page: add it to `PAGES` in `build.py`, add a renderer of the same key
in `assets/renderers.js`, and add the nav entry to `PAGES` in `assets/app.js`.

## House rules enforced by QA

No gradients. No pill shapes or circular radii. No emoji. No entrance or scroll
animation. No em dashes. No inline event handlers. No invented metrics,
testimonials, sponsors or players. Anything unsourced renders as TBC or as an
explicit empty state.
